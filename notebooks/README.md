# Mehfooz Data Science & GLOF Modeling Notebooks

This directory contains Jupyter notebooks for exploratory data analysis, satellite imagery masking, risk sensitivity calibration, and multilingual early warning experiments.

### Available Notebooks:
- `01_glof_satellite_analysis_and_risk_modeling.ipynb`: Interactive demonstration of synthetic Sentinel-2 lake image creation, pixel-level water area detection, dynamic risk engine scoring, and translation fanout to Urdu, Sindhi, and Pashto.

### Running with Jupyter:
```bash
pip install jupyter
jupyter notebook
```
Open `01_glof_satellite_analysis_and_risk_modeling.ipynb` and run all cells.
